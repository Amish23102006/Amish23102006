### Architecture

```mermaid
flowchart TD
    U["User / No-code Console"]
    O["LangGraph Orchestrator"]
    A1["Medical Agent 1"]
    A2["Medical Agent 2"]
    A3["Medical Agent 3"]
    AN["Medical Agent N"]
    M["MCP Server Layer"]
    R["Combined Result"]

    U --> O
    O --> A1
    O --> A2
    O --> A3
    O --> AN

    A1 --> M
    A2 --> M
    A3 --> M
    AN --> M

    M --> R
    R --> U
```

**Key features**

- 🧩 Reusable agents exposed as MCP tools.
- 🔗 Multi-agent orchestration with LangGraph.
- 🖱️ No-code pipeline composition.
- 🏥 Support for multiple medical domains.

**Links:** [Live Demo](https://medagent-rust.vercel.app) · [GitHub Repository](https://github.com/Amish23102006/medagent)
